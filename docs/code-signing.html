Code signing policy

Kod imzalama politikası · How My Screen release binaries are built and signed.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Durum / Status: My Screen'in SignPath Foundation'a başvurusu hazırlık aşamasındadır. Onaylanana kadar yayınlanan kurulum dosyaları imzasızdır. / The application to SignPath Foundation is in preparation; until it is approved, released installers are unsigned.

Build and signing process

  • Every installer is built from this repository's source by GitHub Actions (.github/workflows/build.yml).
  • Third-party files bundled in the installer are downloaded from their official releases with pinned versions and SHA-256 checks (scripts/fetch-vendor.ps1): FFmpeg (LGPL v3, BtbN builds) and Virtual Display Driver (MIT, already signed by SignPath Foundation). These upstream binaries are included unsigned/as-is and are not signed with this project's certificate.
  • Releases are created as drafts and every release is approved manually before publishing and signing.
  • All team members use multi-factor authentication for GitHub and SignPath.

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

My Screen streams the screen only to the phone or tablet that the user connects on their own local network (Wi-Fi hotspot or USB tethering). The connection is encrypted (HTTPS/WSS with a certificate generated on the user's computer) and accepted only from private network addresses with the secret key in the QR code. The app makes no internet requests and contains no telemetry. Bundled components (FFmpeg, Virtual Display Driver) are used locally and do not transfer data.

Bu program, kullanıcı ya da kurulumu yapan/çalıştıran kişi özellikle istemedikçe hiçbir bilgiyi başka ağ sistemlerine göndermez. Ekran görüntüsü yalnızca kullanıcının kendi yerel ağında bağladığı cihaza gider.

System changes and uninstallation

The installer shows these changes before installing: it installs Virtual Display Driver (only if none is present), creates C:\VirtualDisplayDriver with write access for users, and adds a Windows Firewall rule allowing connections from local network addresses only. Uninstalling (Settings → Apps → My Screen) removes the firewall rule and the driver, if the installer added it.
